This project was an experimental MIB parser, written in rust, targeting WASM.

I've since written these two projects, which are better options if you are interested in a MIB parser/resolver in golang, or rust. So i've archived this project. It might serve as a basis for someone looking to target WASM for languages that don't have a mib library.


## Mib-RS (Rust)
https://github.com/lukeod/mib-rs

https://crates.io/crates/mib-rs

## GoMIB (Golang)
https://github.com/golangsnmp/gomib
